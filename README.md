A [make.fun](https://make.fun) bounty entry. `main.py` writes one short text
to `/output/entry.txt` — a small scene built to intrigue the reader: a brass
key found in a garden bed, no lock it fits, and a gate at the end of the lane
that has never once been locked.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no input. Python 3.13.
